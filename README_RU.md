# Real Scale Procedural Moon v12

Проект для Godot 4.7.1, собранного с `precision=double`.

## Главное в v12

- Entity Registry v1 подключён к игроку;
- игрок имеет постоянный `entity_id`;
- переходы между зонами и чанками фиксируются событиями;
- структурированные логи JSONL;
- диагностический снимок по `F9`;
- мини-тест миграции по `F7`;
- отключаемое меню по `F1` или `Esc`.

## Управление

```text
F1 / Esc   открыть или закрыть меню
Tab        захватить или освободить мышь
F7         мини-тест миграции сущности
F9         сохранить диагностический JSON
F3         персонаж / спектатор
F6 / R     случайная точка Луны
F8         сменить разрешение
F11        полный экран / окно
```
