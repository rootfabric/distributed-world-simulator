LIVE2_REQUIRED_REPAIRS =
1. uint16 rollover в транспортном счётчике клиент→сервер (disconnect на
   65536 исходящих сообщений). Критерий приёмки: клиент живёт >2ч активного
   движения, tx > 131072 без разрыва.
2. Connection UX: постоянная видимая индикация связи; при разрыве —
   баннер/лобби + автореконнект (или явная кнопка).
3. Construction MVP: подключить place_selected_item_from_view к input'у;
   предмет "блок строительный"/mount-base; постановка на поверхность и
   блок-на-блок; первый блок создаёт construct-грид; ghost + честные ошибки.
   (Runtime-модель construct/parts/bonds/build-plans уже существует.)
4. Движение: interpolation buffer для удалённых акторов + починка
   reconciliation-осцилляции своего персонажа (+ physics-interpolation
   warning).
5. Mining: получить/экипировать/применить инструмент — полный человеческий
   путь, чтобы цепочка руда→материалы заработала.
6. Inventory UX: Esc-закрытие; разделение режимов ввода UI/игры;
   гарантированный видимый ответ на каждое действие (никаких silent no-op);
   развести семантику "выбросить"/"поставить".
7. Hotbar-контент: предметы с функциями для панели быстрого доступа.
8. Надёжность сервера: расследование тихих смертей (heartbeat/supervisor),
   чаще flush логов, поштучное логирование rejections.
