# Landmark Markers v1

## Задача

На однообразной лунной поверхности легко потерять базу или маяк. Полные сцены маяков загружаются только в Warm/Active чанках, поэтому они не подходят для дальней навигации.

## Решение

Создан отдельный лёгкий глобальный индекс:

```text
user://worlds/moon-experiment-001/landmarks.json
```

Он содержит только:

```text
entity_id
world_position
label
marker_type
max_distance_m
```

Полный объект маяка по-прежнему хранится в chunk JSON.

## Отображение

Для каждого landmark создаётся лёгкий Label3D:

- billboard;
- fixed screen size;
- no-depth-test для навигационной видимости;
- расстояние до маяка;
- дальность по умолчанию 250 км;
- автоматическое обновление при render-origin shift.

Клавиша `M` включает и выключает дальние метки.

## Совместимость со старыми мирами

Если `landmarks.json` отсутствует, индекс один раз восстанавливается сканированием изменённых chunk JSON. Процедурные пустые чанки при этом не сканируются, потому что файлов для них нет.

## Связь с terrain cache

Cells, содержащие маяки, передаются streaming manager как pinned. После посещения такой cell её готовая LOCAL-поверхность удерживается в памяти дольше обычных участков.
