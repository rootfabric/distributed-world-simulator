# Постоянный изменяемый слой мира v1

## Решение

Процедурная Луна не сериализуется как набор готовых мешей. Авторитетная базовая поверхность восстанавливается из:

```text
world_seed + generator_version + координата
```

На диск записывается только изменяемый слой:

- размещённые сущности;
- состояние их компонентов;
- позднее — операции изменения грунта;
- журнал операций.

## Формула мира

```text
Итоговая сцена
=
процедурная основа
+
постоянные сущности чанка
+
terrain deltas чанка
```

## Жизненный цикл чанка

```text
Dormant
  данных чанка нет в памяти

Warm
  прочитан JSON изменяемого слоя
  сущности зарегистрированы

Active
  созданы визуальные и физические узлы сущностей
```

В первой итерации Warm и Active используют одно окно загрузки, но контракт хранения от этого не зависит. Позже эти состояния будут разделены сильнее.

## Разреженное хранение

Файл чанка существует только тогда, когда в нём есть постоянные сущности или terrain deltas.

```text
неизменённый процедурный чанк → файла нет
чанк с маяком              → небольшой JSON
удалён последний объект    → JSON удаляется
```

## Не является авторитетным состоянием

- ArrayMesh;
- ConcavePolygonShape3D;
- normal/tangent arrays;
- процедурные декоративные камни;
- LOD-меши;
- camera-relative координаты.

Позже эти данные могут появиться в удаляемом кэше, но не в сохранении мира.
