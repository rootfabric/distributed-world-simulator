# ADR-001: разделить рендерное и симуляционное разбиение

**Статус:** принято  
**Версия:** v11

## Контекст

Для плавной поверхности Луны необходимы непрерывные LOD-меши. Для сохранения,
роботов и будущего горизонтального масштабирования нужны устойчивые чанки.

## Решение

Использовать две независимые сетки:

- render LOD — GLOBAL/REGIONAL/LOCAL/ULTRA;
- simulation partition — cube face/zone/chunk.

## Последствия

Плюсы:

- серверные границы не создают трещины в графике;
- размер симуляционного чанка можно менять независимо от LOD;
- одна зона может обслуживать несколько рендерных патчей.

Минусы:

- потребуется слой сопоставления terrain delta с рендерным мешем;
- диагностика должна показывать обе системы отдельно.
