# ADR-002: cube-sphere адресация Луны

**Статус:** принято  
**Версия:** v11

## Контекст

Широта/долгота создаёт сходимость ячеек у полюсов и неудобна для равномерного
разделения нагрузки.

## Решение

Использовать шесть граней cube-sphere. На каждой грани применяется регулярная
двумерная сетка зон и чанков.

## Последствия

- отсутствует особая полярная зона;
- адрес компактен и детерминирован;
- переходы между гранями требуют преобразования через направление, а не простого
  сложения индексов;
- реальный размер ячейки остаётся неидеально равномерным, но подходит для
  симуляционных участков.
