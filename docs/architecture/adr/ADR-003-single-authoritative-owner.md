# ADR-003: один авторитетный владелец изменяемого чанка

**Статус:** принято как инвариант  
**Версия:** v11

## Решение

Каждый изменяемый Zone/Chunk имеет один `owner_token`.

Сейчас:

```text
owner_token = local-process
```

Позже:

```text
owner_token = site-server-shackleton-03
```

## Причина

Без единственного владельца два процесса могут одновременно:

- переместить одного робота;
- изменить один voxel;
- поставить два модуля в одно место;
- записать несовместимые terrain delta.

Передача владения должна быть отдельной транзакцией, а не побочным эффектом
сетевой синхронизации.
