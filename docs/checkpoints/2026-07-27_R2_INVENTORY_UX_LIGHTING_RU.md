# Checkpoint v16.3.0-r2-inventory-ux

## Цель

Упростить ручное перемещение предметов, убрать ложный внешний контейнер из обычного инвентаря, учитывать разные размеры контейнеров и сделать круговой фонарь реально полезным на тёмной поверхности.

## Исправления

- UI-generated operation IDs получают криптографически случайный session namespace. Перезапуск runtime больше не переиспользует ID из persistent operation ledger и не создаёт `OPERATION_ID_CONFLICT` при обычном drag-and-drop.
- ЛКМ всегда переносит весь стак без предварительного состояния.
- ПКМ удерживается во время перетаскивания; после выбора допустимой цели открывается окно количества. До подтверждения item graph не меняется.
- Удалены постоянная жёлтая подсветка и режим «подготовленного переноса».
- Drop target предварительно проверяется без мутации graph: slot rules, stack compatibility, max stack и entry capacity.
- Обычный `Tab` показывает только рюкзак и hotbar. Внешняя секция появляется только после `E` на WORLD-предмете, который владеет контейнером, и забывается после закрытия инвентаря.
- BULK и SLOTS контейнеры отображают собственный `slot_count`; UI меняет количество колонок и включает вертикальную прокрутку для больших контейнеров.
- Фонарь состоит из широкого 1000-метрового OmniLight fill и отдельного ближнего OmniLight. Оба слоя отключают тени, чтобы не создавать тяжёлый GPU cost.

## Проверяемые сценарии

- full-stack LMB drag;
- right-button drag, target selection, post-drop quantity confirmation;
- split в пустой fixed slot без промежуточной подсветки;
- stack-on-stack и overflow remainder;
- запуск новой UI-сессии поверх сохранённого operation ledger;
- `Tab` без внешнего контейнера;
- `E` на 12-entry BULK crate и 4-slot battery rack;
- корректное число визуальных ячеек;
- включение и выключение обоих слоёв фонаря;
- отдельный render probe сравнивает полностью тёмный кадр и освещённый terrain frame.
