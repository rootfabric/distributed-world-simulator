# ECO.EVO4/E4.B0.5 — Rich Presentation Spike

Статус: `RESEARCH_ONLY / PRESENTATION_SPIKE / NO_ACCEPTANCE_CLAIM`.
Дата: 2026-08-22. Выполнен параллельно волне 2 по протоколу бесконфликтности (только новые файлы; PH5-core не тронут; волночные артефакты не задеты).

## Что добавлено

Новый presentation-layer модуль `scripts/research/ecology/evo4_bridge_presentation_v1.gd` поверх принятой цепочки PH1→PH5:

- **Изгиб ствола тропизмом**: когерентное смещение всей геометрии функцией высоты (направление/амплитуда/вобл — из сида);
- **Презентационные твиги** на терминалах скелета (derived geometry, не меняют graph_hash);
- **Мутовки листа по золотому углу** на всех терминалах обогащённого набора (3 листа на твигах, 6–8 на настоящих);
- **Архетипы листа** (lanceolate / rounded / needle) — выбор **по чек-сумме вида**, стабилен между особями;
- **Цветовая ДНК вида**: палитра листвы/ствола из чек-суммы вида + metabolic-поля (water_preference → сдвиг тона, shade_tolerance → темнее); per-instance джиттер ±8%; вертикальный градиент древесины;
- **Цветы-дериват dormancy**: плотность = clamp(0.55 − dormancy_fraction); косметика из принятых полей, НЕ новые гены;
- **Когорты**: 3 особи на вид с сидами base+c·7919 и масштабами 0.85/1.0/1.18;
- **Сцена**: детерминированный скаттер (150 пучков травы, 18 камней), золотой час (тёплый key + холодный fill), туман глубины 0.005, градиентное небо;
- Каждый стохастический выбор ключуется `(individual_seed | traits_checksum | label)` → `presentation_hash` фиксирует состав кадра.

## Исправления в ходе спайка

1. Архетип/палитра переведены с сида особи на чек-сумму вида (иначе когорты одного вида выглядели разными видами).
2. `Camera3D.look_at` вызывался до `add_child` — порядок исправлен.
3. Терминалы разделены: исходные (для твигов) и обогащённые (для мутовок).

## Известные заметки

- Индивидуальные сиды проходят через JSON-parse как float: значения выше 2^53 дают дрейф последних цифр (детерминизм внутри прогона сохранён; для точного совпадения с python-сидами нужен строковый парсинг — кандидат в B2/B6 контракты).
- Разреженность `alpha-late` (apical 0.60 → ~1 ветвь) — честный сигнал генома (узкая спиральная форма), не дефект.
- Шаги волн не затронуты; гейты B3/B4 применяют этот рендер как есть.
