# ECO.P1 — Plant Adaptation and Strategy Proof — ACCEPTED

`ECO.P1A`, `ECO.P1B` и `ECO.P1C` приняты.

Итог P1:

1. continuous environment fields дают причинные resource consequences;
2. mutation/inheritance + selection создают local adaptation без predefined species;
3. heterogeneous world поддерживает несколько конкурирующих unlabeled strategies;
4. uniform controls не создают ложную spatial niche structure;
5. результаты детерминированно replay-ятся.

Граница принятия: P1C — ecological-trait-only proof. Morphology пока не является частью competition truth. Следующий шаг — ECO.PH: `genome -> deterministic development program -> GrowthGraph`, затем plasticity и morphology-to-resource coupling.
