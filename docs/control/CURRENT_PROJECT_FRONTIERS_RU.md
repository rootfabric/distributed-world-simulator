# Текущий маршрут проекта

Этот файл — указатель, а не самостоятельная таблица статусов. Точный срез с commit каждой ветки выдаёт `CONTROL_DEVELOPMENT.ps1 -Overview`; цели и порядок этапов описаны в [плане развития](../plans/PROJECT_DEVELOPMENT_FOCUS_RU.md).

Источники: `project-goals.v1.json → lane_goals` и `project-program-registry.v1.json → coordination`. Исполнение разрешают scheduler, catalog, activation и Work Order. Обзор отличает продвинувшуюся ветку от сохранённого источника доказательств и сам не делает fetch.

| Направление | Назначение | Отношение к MVP |
| --- | --- | --- |
| MVP | Общая визуальная сцена, несколько клиентов, бесшовная сеть, изменяемая среда и persistence | Главный приоритет |
| ECO | Генетический полигон; workbench, simulation и VIS в одной сессии | Параллельное исследование, позднее передача каталогов/рецептов |
| FABRIC | Детали и связи, сложные машины, корректное запекание и наблюдение | Параллельное исследование, перенос после доказательства полезности |
| PRESENTATION | WORLD FILL + WORLD PACKS через существующих владельцев | Необязательные ограниченные дополнения |

До принятия control-изменения в main предложенный срез доступен через `CONTROL_DEVELOPMENT.ps1 -Overview -Candidate`. Candidate не разрешает dispatch и не объявляет acceptance. Нельзя смешивать его поля с main без указания происхождения.

Старые версии этого файла сохраняются в Git. Их отметки NEXT относятся к старому срезу и не используются для выбора новой задачи.
