# ECO EVO4.T — Мега-волна T1–T4 (закрытие лейна за один диспатч)

Статус: `RESEARCH_ONLY / EXECUTION_PLAN / AUTHORIZED_BY_DIRECTOR_SESSION_DISPATCH`.
Цель: закрыть большую часть горизонта E4.T одним последовательным прогоном с поэтапными гейтами. База: T0 PASS 4/4 (`6f1b3cb0`).

## Шаги (строгий порядок, каждый со своим гейтом и коммитом)

### 1. T1 — Herbivore agent contract
`evo4_t1_herbivore_agent_v1.py`: переносимый агент `{appetite, mobility, preference_vector(v0: nutrient_value↑, toxicity↓)}`; агрегатное давление на патч поверх PopulationPatch-семантики (без individual truth). Гейт: детерминизм fresh-process; давление монотонно по appetite; тесты.

### 2. T2 — Coevolution loop
`evo4_t2_coevolution_loop_v1.py`: N=40 поколений «растения сдвигают defense-распределение ↔ агенты смещают предпочтение» на 9 видах моста (payoffs из T0). Гейты: недоминируемость чистых стратегий (аналог PH3C); restart-determinism байт-в-байт; robustness на 3 сидах. Артефакт траектории + результат-верdict.

### 3. T3 — Defense visualization (Godot)
Презентер получает `thorn_density` из defense-прокси (шипы-конусы на ветвях, презентационный слой) + следы объедания при давлении. Лаба: 9 видов до/после давления, подписи в кадре. Гейт: PASS-прогон, пиксельная проверка, скриншот `artifacts/evo4_t3_trophic_defense.png`.

### 4. T4 — Планетарный трофический прогон
Поверх манифеста B6 (polar-plateau-04/extended_r1): распределения defense из равновесия T2 → классы защиты экземпляров; повторный B7-probe на том же регионе. Гейты: хеши цепи неизменны; fps ≥ бюджет; финальный кадр `artifacts/evo4_t4_planetary_trophic.png`.

### 5. Закрытие
Evidence-чекпоинты по каждому шагу; трекер: E4.T → `COMPLETE_T0_T4`; предизайн-статусы обновлены; push после каждого шага (явные пути). Merge PR #196 остаётся human gate для канонизации всего моста+E4.T.

## Правила

Новые гены — запрещены (только прокси v0); population truth — запрещена; принятые ядра не трогаются; откат любого шага = один revert. Оценка объёма: ~4 коммита кода/артефактов + 1 чекпоинт-коммит.
