# ECO EVO4.T — Multi-Trophic Ecosystem & Coevolution: Pre-Design

Статус: `RESEARCH_ONLY / NON_AUTHORITATIVE_PREDESIGN`. Дата: 2026-08-22.
Диспатч Director: получен в сессии («реализуй следующий горизонт») после закрытия лейна E4.B (B0–B7 все PASS).

## 1. Задача

Исходная declared goal EVO4: **multi-trophic ecosystem and coevolution**. Растительный мост (E4.B) сделал морфологию видимой и связанной с условиями; теперь трофические взаимодействия должны стать частью того же причинного контура: defense/шипы/токсичность — признаки, на которые травоядные отвечают давлением, а растения — эволюцией защиты.

## 2. Принятый фундамент (переиспользуем, не изобретаем)

| Механизм | Источник | Роль в E4.T |
|---|---|---|
| Pairwise morphology-aware selection | `ECO.PH3C` ACCEPTED | Каркас коэволюционного отбора «морфология × давление» |
| Морфология-экономика (crown/root/payoffs) | `ECO.CAL1-A..F` ACCEPTED | Цена защиты в ресурсном балансе |
| Seed lifecycle / dispersal | `ECO.PH4`, EVO1 P2 | Давление травоядных на расселение |
| Species catalog + bridge (B1/B2) | этот лейн | Носитель трофических признаков видов |
| Rich presentation + region materialization (B0.5/B6/B7) | этот лейн | Видимая защита: шипы, жёсткость листа, окрас |

Инварианты наследуются: population is truth; планетарная индивидуальная истина запрещена; presentation не меняет хеши цепи; ретюнинг принятых ядер запрещён.

## 3. Разделение genome (аддитивно, поверх B1-v1)

Трофический блок (кандидаты): `defense_intensity` (шипы/жёсткость), `toxicity`, `regrowth_rate`, `nutrient_value`. Честность B1-v1: новые гены вводятся ТОЛЬКО вместе с двусторонней связью к causal model (цена защиты платится в CAL1-механизмах) и отдельной авторизацией. До тех пор — деривационные прокси v0 от metabolic-полей (как в B1-v0).

## 4. Эскиз лейна

- **E4.T0 — trophic payoff probe** (python): детерминированная матрица «давление травоядных × defense-прокси» по 9 видам моста; sealed directions по образцу B3; артефакт + тесты. Проверяем: у защиты есть цена и порог окупаемости.
- **E4.T1 — herbivore agent contract**: переносимый агент (голод, подвижность, предпочтение nutrient_value/против toxicity) поверх PopulationPatch-семантики; без individual truth — агрегатное давление на патч.
- **E4.T2 — coevolution loop**: цикл «растения мутируют защиту ↔ агенты смещают предпочтение»; гейты: недоминируемость чистых стратегий (аналог PH3C), restart-determinism, cross-seed robustness (по образцу EVO2).
- **E4.T3 — визуализация трофики**: defense → плотность шипов/толщина кутикулы в rich-presenter (presentation-side); agent presence → следы объедания (детерминированные деформации кроны); кадры до/после давления.
- **E4.T4 — планетарный прогон**: трофический слой поверх материализации региона B6 на комбинациях E3.FINAL; гейт: хеши цепи неизменны, наблюдаемая трофика согласована с программой.
- **Горизонт**: хищники/разложение — за пределами этого предизайна.

## 5. Открытые вопросы

1. Агрегатное давление vs промотированные особи травоядных (PH6-зависимость).
2. Скорость коэволюционного цикла в поколениях vs сезонность E3.6-R.
3. Момент ввода независимых трофических генов (B1-v1-стиль) — требует авторизации ретунинга causal coupling.
