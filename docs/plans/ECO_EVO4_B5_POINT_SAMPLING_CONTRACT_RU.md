# ECO.EVO4/E4.B5 — Контракт сэмплирования условий в точке планеты

Статус: `RESEARCH_ONLY / BRIDGE_CONTRACT / NO_ACCEPTANCE_AUTHORITY`.
Правило: **NEAREST-SAMPLE** (ближайший сэмпл), зафиксировано настоящим документом.

## 1. Источник условий

Принятые артефакты E3.FINAL unseen-планетных полей:

`config/ecology/accepted_inputs/e3_final/e3_final_unseen_planet_field_snapshot.<planet>.v1.json`

Каждый сэмпл несёт геометрию и условия (реальные ключи):

- геометрия: `latitude_microdeg`, `longitude_microdeg` (int, микро-градусы);
- условия: `light_availability_ppm`, `soil_moisture_ppm`, `nutrient_availability_ppm`, `disturbance_pressure_ppm`, `temperature_milli_c`;
- идентичность: `sample_id`, `stable_spatial_key`, `sample_hash`.

## 2. Решение: NEAREST-SAMPLE (билинейное отклонено)

**Билинейная интерполяция отвергнута по правилу честности**: она синтезирует условия между сэмплами, которых никто не наблюдал, и создаёт ложную гладкость на разреженной планетарной сетке. NEAREST возвращает только реально существующий сэмпл — каждое условие трассируется к одному принятому `sample_hash`.

## 3. Правило отбора

1. Вход: `(latitude_microdeg, longitude_microdeg)` — int или конечный float.
2. Метрика: квадрат евклидова расстояния в микро-градусах `d² = Δlat² + Δlon²`. Плоское приближение объявлено сознательно: отбор идёт между дискретными сэмплами регионального бассейна, а не непрерывная навигация; сферическая поправка не требуется для выбора ближайшего из локальной сетки. Известное ограничение: вблизи антимеридиана (±180°) сырые долготы сравниваются напрямую — сетки сэмплов E3.FINAL региональны, пересечения антимеридиана не заявлены; если появятся — контракт пересматривается.
3. Отбор: минимум по кортежу `(d², stable_spatial_key)` — лексикографический tie-break делает результат независимым от порядка кандидатов и детерминированным при симметричных случаях.
4. Точный попаданец (d² = 0) возвращается как есть.
5. Возвращаемые условия — копия значений `CONDITION_KEYS` выбранного сэмпла; идентичность/хеши не включаются в условия, но `stable_spatial_key` и `sample_id` возвращаются рядом для трассировки.

## 4. Fail-closed ошибки (порядок проверки фиксирован)

| Порядок | Код | Условие |
|---|---|---|
| 1 | `EVO4_SAMPLE_EMPTY_INDEX` | индекс без сэмплов |
| 2 | `EVO4_SAMPLE_NONFINITE_POINT` | NaN/inf или нечисловой вход |
| 3 | `EVO4_SAMPLE_OUT_OF_EXTENT` | широта вне [−90 000 000, +90 000 000] или долгота вне [−180 000 000, +180 000 000] микро-градусов |

## 5. Детерминизм и чистота

Модуль чистый: без IO, часов, случайности и глобального состояния; одинаковые входы дают побайтно одинаковый результат. Реализация: `scripts/research/ecology/evo4_point_sampling_v1.py`; тесты: `tests/research/ecology/test_evo4_point_sampling_v1.py` (синтетическая копия формы реального артефакта + smoke-тест по реальному файлу `arid-basin-02`).
