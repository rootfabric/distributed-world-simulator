# ECO EVO4 — План реализации моста (волны B1–B7)

Статус: `RESEARCH_ONLY / EXECUTION_PLAN / NON_AUTHORITATIVE`.
База: main `5c0b5392` (после acceptance-merge PR #193). Предусловия: E3.FINAL ACCEPTED, E4.B0 PASS.
Дисциплина: каждая волна стартует отдельным authorization dispatch Director; каждый шаг несёт собственные closure-гейты; merge каждого PR — human gate; принятые поверхности E3.x не изменяются.

## Волна 1 — независимые дешёвые шаги (можно параллельно)

### E4.B1 — DevelopmentTraits как research-расширение каталога
- **Цель**: закрепить деривацию v0 из B0 как именованный контракт и выпустить расширенный артефакт каталога (по прецеденту `evo2_persisted_species_catalog.e3_final_extended_r1.v1.json`).
- **Работы**: контракт-схема правила деривации (формулы, bounds, алгоритм checksum); детерминированный генератор `evo4_bridge_catalog_extender_v1.py` → артефакт `evo2_persisted_species_catalog.evo4_b1_dev_traits.v1.json` с provenance (source catalog hash + rule id); тесты: валидация PH0 всех traits, fresh-process rebuild equality, back-compat (исходный каталог остаётся каноничным входом), запрет мутации принятых артефактов.
- **Гейты**: детерминизм; бит-в-бит checksum совместимость; provenance binding; независимое ревью.

### E4.B5 — Контракт сэмплирования условий в точке планеты
- **Цель**: объявить детерминированное правило «координата → условия» по сэмплам E3.1/E3.2 (nearest-patch vs билинейное — выбрать одно, зафиксировать tie-break).
- **Работы**: контракт-документ + чистый Python-модуль + тесты на краях сетки, совпадении координат с патчем, отрицательных/вне-диапазона координатах (fail-closed).
- **Гейты**: детерминизм; полнота краевых случаев; ревью контракта до реализации потребителей.

## Волна 2 — bridge-компилятор

### E4.B2 — Компилятор «запись каталога × условия × сид × возраст → DevelopmentState/GrowthGraph params»
- **Зависимости**: B1 (расширенный каталог), B5 (сэмплирование точки).
- **Работы**: unit-mapping контракт (ppm opportunity → ресурсная шкала грамматики) — таблица единиц в контракте; компилятор `evo4_bridge_compiler_v1.py`; демографический синтез возрастов когорт из (establishment order, disturbance-история, lifespan_years) — без population truth; JSON-артефакт параметров + тесты.
- **Гейты**: детерминизм fresh-process; declared units обязательны до кода; отсутствие притязаний на truth; ревью.

## Волна 3 — гейты качества формы

### E4.B3 — Sealed plasticity gate на EVO3-условиях
- **Работы**: матрица «фиксированный генотип × направления условий» (сухо/влажно/тень/disturbance); предрегистрация ожидаемых направлений метрик GrowthGraph (высота, радиус кроны, средний угол латерали) в sealed-артефакт; прогон через B2; вскрытие и сверка (паттерн E3.FINAL reveal).
- **Гейты**: 12/12 печатей верифицированы; направления согласованы с предрегистрацией; неоднозначность = fail-closed.

### E4.B4 — Гейты разнообразия и различимости
- **Работы**: фич-вектор blueprint'ов (height, crown radius, branching depth, leaf density proxy, lateral angle) из summaries GrowthGraph (не mesh!); порог покрытия против коллапса по N генотипам×условия×сиды; silhouette fingerprint: межвидовое расстояние > внутривидовой вариации (один геном, разные сиды).
- **Гейты**: пороги объявлены до прогона; протокол повторяем; ревью метрики.

## Волна 4 — материализация и масштаб

### E4.B6 — Materialization региона из принятой программы
- **Зависимости**: B2, B4 (гейты зелёные), B5.
- **Работы**: потребитель формата программ E3.7/E3.FINAL → спавн экземпляров по регионам с когортными возрастами; рендер тирами PH5-S3; фиксированные камеры-риг; скриншот-evidence (MCP_GODOT при доступном хосте, иначе self-capture как в B0); тест asset-pack swap invariance (замена орган-мешей не меняет ни одного hash цепи).
- **Гейты**: соответствие программы (число экземпляров/регионов сверено с артефактом); инвариантность хешей; визуальное evidence.

### E4.B7 — Scale/perf probe
- **Зависимости**: B6.
- **Работы**: регион ~1000 экземпляров под политикой тиров (дальние TIER_2/3/POPULATION_ONLY); измерение frame time / instance counts; отчёт бюджетов как вход CONV0-A/WQ-WB.
- **Гейты**: воспроизводимость замеров (3 прогона); отчёт без product-притязаний.
