# Следующие итерации

## Выполнено в v11

- cube-sphere зоны;
- логические чанки;
- Active/Warm окно;
- snapshot `lunar.partition.v1`.

## Выполнено в v12

- Entity Registry v1 подключён к игроку;
- постоянный `entity_id` игрока;
- события переходов между чанками и зонами;
- entity_count в загруженных чанках;
- структурированные JSONL-логи;
- диагностический snapshot по F9;
- runtime и headless мини-тест миграции;
- отключаемое меню F1/Esc.

## Следующая итерация v13 — локальное сохранение

1. `WorldManifest` и `world_id`.
2. Каталог `user://worlds/<world_id>/`.
3. Сохранение Entity Registry.
4. Dirty flags для изменённых чанков.
5. Атомарная запись через временный файл и rename.
6. Загрузка игрока и тестового объекта после перезапуска.
7. Версионирование и миграции схемы.

Критерий готовности: размещённый тестовый объект и его chunk address
восстанавливаются после полного перезапуска проекта.
