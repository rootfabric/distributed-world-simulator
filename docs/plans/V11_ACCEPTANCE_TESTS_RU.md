# Проверки v11

## Запуск

- проект открывается double-сборкой Godot;
- персонаж появляется на поверхности;
- спектатор и LOD работают как в v10;
- F8/F11 работают.

## Структура

- `main.tscn` использует `scripts/app/lunar_app.gd`;
- новые модули не импортируют compatibility wrappers;
- terrain implementation доступна через `world/moon_world.gd`.

## Зоны и чанки

В HUD должна появиться строка вида:

```text
Разбиение: F4 Z17,09 | F4 Z17,09 C03,28 | zones=9 chunks=49 active=25 warm=24
```

Допустимы другие числа около границ cube face.

Проверить:

1. При ходьбе меняется chunk address.
2. При длительном полёте меняется zone address.
3. Количество runtime-зон не растёт бесконечно.
4. После случайного спавна адрес меняется сразу.
5. Переключение персонаж/спектатор не ломает разбиение.

## Регрессии

- нет второго физического слоя;
- персонаж не проваливается;
- не возвращается чёрное пятно центра LOD;
- локальные материалы и камни отображаются;
- Q/E работают в принятом направлении.

## Автоматический запуск

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\RUN_ARCHITECTURE_TESTS.ps1
```

Скрипт запускает `tests/unit/test_partition_foundation.gd` через double-precision
Godot в headless-режиме.
