# Приёмочные тесты v13

## Автоматический тест

```powershell
.\RUN_PERSISTENCE_TEST.ps1
```

Ожидаемый результат:

```text
Persistent world integration tests: PASS
```

## Runtime mini-test

Нажать `F10` или кнопку **Тест сохранения**.

Проверяется цепочка:

```text
создать тестовый маяк
→ записать JSON чанка
→ выгрузить сущности чанка из памяти
→ прочитать JSON
→ восстановить EntityRecord
→ восстановить визуальный узел
→ удалить тестовый маяк
```

## Главный ручной тест между перезапусками

1. Нажать `B` и поставить маяк.
2. Нажать `Ctrl+S`.
3. Полностью закрыть проект.
4. Запустить проект снова.
5. Вернуться к той же точке Луны.
6. Маяк должен появиться в том же месте.
7. Удалить его клавишей `Delete`.
8. Перезапустить проект ещё раз.
9. Удалённый маяк не должен восстановиться.

Для быстрого возврата сохраните широту и долготу из HUD либо не используйте случайный спавн между запусками в этом тесте.
