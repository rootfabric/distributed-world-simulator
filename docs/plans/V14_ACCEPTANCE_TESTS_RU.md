# Приёмочные тесты v14

## Ручной тест камеры

1. Запустить проект.
2. Закрыть меню через F1.
3. Убедиться, что включено первое лицо.
4. Нажать C — должно появиться третье лицо и модель астронавта.
5. Подойти спиной к склону: SpringArm не должен пропускать камеру сквозь поверхность.
6. Ещё раз нажать C и вернуться в первое лицо.

## Ручной тест Lunar EVA

1. Выбрать `Lunar EVA` через J или меню.
2. Проверить WASD, Shift и прыжок Space.
3. Проверить движение по склонам и падение под лунной гравитацией.

## Ручной тест Jetpack

1. Нажать J.
2. Space — подъём.
3. Ctrl — снижение.
4. WASD — горизонтальное движение.
5. Shift — ускоренная тяга.
6. Нажать J повторно: персонаж должен вернуться к обычной физике и начать падать, если находится в воздухе.

## Мини-тест

Нажать F12. Ожидаемый результат:

```text
PASS: lunar_humanoid ↔ lunar_jetpack, first_person ↔ third_person
```

Тест переключает контроллер и камеру, проверяет активную Camera3D, затем восстанавливает исходное состояние.

## Headless-тест

```powershell
.\RUN_CONTROLLER_TEST.ps1
```

Проверяются JSON-профили, уникальные ID, существование controller scripts и методы контракта.
