# Приёмка v15.5 — Multi-world Simulator Core

## Цель среза

До развития контейнеров и строительства стабилизировать общее ядро, чтобы
увеличение числа миров не создавало отдельные ветки управления, меню и тестов.

## Реализовано

- единая точка входа `SimulatorApp`;
- каталог миров в JSON;
- пять начальных конфигураций мира, включая отдельный `EarthApp`;
- загрузка runtime из скрипта или готовой сцены;
- безопасная выгрузка активного мира;
- универсальный реестр команд, включая общие `world.*`, `input.*`, `display.*`;
- классическая консоль по `~`;
- история и автодополнение команд;
- реестр тестов активного мира;
- запуск тестов из консоли и командной строки;
- плоский humanoid-контроллер через общий `ControllerHost`;
- закрытая площадка для движения персонажа;
- сохранение существующих Lunar, Earth, Earth-Moon и Item Lab реализаций.

## Обязательная автоматическая проверка

```powershell
.\RUN_WORLD_REGRESSION_TESTS.ps1
```

Скрипт автоматически ищет Godot в `GODOT_BIN`, `PATH` и стандартных папках.
Он выполняет:

1. тест парсера, aliases, кавычек и owner-lifecycle команд;
2. валидацию каталога миров;
3. проверку всех встроенных controller profiles и legacy-совместимости;
4. все существующие unit/integration тесты partition, atmosphere, Earth,
   persistence, interaction и terrain streaming;
5. domain и scene-integration тесты предметов и контейнеров;
6. существующие unified architecture tests;
7. последовательную загрузку всех пяти миров;
8. проверку обязательных и запрещённых команд каждого мира;
9. проверку повторного открытия консоли без повреждения process mode;
10. запуск зарегистрированных smoke-тестов, включая Earth body isolation;
11. запуск `main.tscn` через CLI-контракт `--world` + `--run-tests`.

## Ручная проверка

### 1. Запуск и консоль

- запустить `main.tscn`;
- убедиться, что стартует `earth_moon`;
- нажать `~`;
- выполнить `help`, `world.list`, `runtime.snapshot`;
- выполнить `display.resolution.cycle` и дважды `display.fullscreen.toggle`;
- проверить историю Up/Down и автодополнение Tab.

### 2. Переключение миров

Последовательно выполнить:

```text
world.load moon
world.load earth
world.load earth_moon
world.load item_lab
world.load playground
world.back
```

Ожидается:

- в дереве существует только один active runtime;
- команды предыдущего мира исчезают;
- команды нового мира доступны;
- консоль и core-команды не пересоздаются;
- повторный `console.open` не оставляет runtime остановленным после закрытия;
- специализированное Lunar diagnostic-меню скрыто при старте и не заменяет
  универсальную консоль;
- мышь и движение продолжают работать одинаково.

### 3. Луна

```text
test.run all
runtime.snapshot
```

Ожидается рабочий Lunar runtime, существующая persistence/terrain архитектура и
минимум один успешный runtime smoke-тест.

### 4. Земля

```text
world.load earth
test.run all
```

Ожидается отдельный `EarthApp`: в `runtime.snapshot` список `body_ids` содержит
ровно `earth`, команда `world.beacon.place` отсутствует, а общие `display.*`
команды остаются доступными. Переход к Луне не является частью конфигурации.

### 5. Земля + Луна

```text
world.load earth_moon
test.run all
```

Ожидается общий double-precision space и доступность обоих тел.

### 6. Лаборатория предметов

```text
world.load item_lab
runtime.snapshot
item.rock.pickup
item.crate.pickup
item.graph.validate
test.run all
```

Ожидается непротиворечивый граф отношений и отсутствие команд планетарного
runtime.

### 7. Площадка

```text
world.load playground
player.reset
test.run all
```

Ожидается плоская закрытая площадка, персонаж и стандартное управление через
`ControllerHost`.

## Критерии завершения

Срез принят, если:

- все пять миров загружаются в одном процессе;
- ни один мир не создаёт альтернативное ядро управления;
- owner cleanup удаляет команды и тесты предыдущего runtime;
- `~` и общие `display.*` команды работают во всех мирах;
- headless regression возвращает код 0;
- существующие unified tests не регрессировали;
- документация соответствует фактическим ID команд и миров.

## Не входит в v15.5

- редактор пользовательских world packs;
- hot reload каталога;
- сетевые права на команды;
- JUnit/CI-экспорт результатов;
- визуальный браузер миров;
- декларативные переназначаемые key bindings;
- полноценный инвентарь персонажа на Playground.
