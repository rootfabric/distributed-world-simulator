# Приёмочные тесты v15 — Async Terrain Streaming

## 1. Контрактный headless-тест

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\RUN_TERRAIN_STREAMING_TEST.ps1
```

Ожидается:

```text
Terrain streaming contract tests: PASS
```

## 2. Runtime мини-тест

1. Запустить проект.
2. Закрыть меню `F1`.
3. Нажать `K`.
4. Дождаться завершения фоновой job и staged commit.
5. Открыть меню.

Ожидается строка:

```text
PASS: background ... ms, commit max ... ms, frame max ... ms
```

Тест запрашивает соседнюю Terrain Streaming Cell и не меняет persistence.

## 3. Ручной тест ходьбы

1. Использовать `Lunar EVA`.
2. Идти или бежать непрерывно 2–3 км.
3. Несколько раз резко изменить направление.
4. Следить за строкой `Terrain streaming`.
5. Проверить отсутствие многосекундной полной остановки.

## 4. Stress test джетпака

1. Нажать `J`.
2. Подняться на 20–80 м.
3. Лететь с `Shift` не менее 5 км.
4. Несколько раз выполнить разворот на 90–180°.
5. Вернуться в Lunar EVA и проверить collision.

## 5. Persistence regression

После async swap:

1. поставить маяк `B`;
2. сохранить `Ctrl+S`;
3. перезапустить проект;
4. убедиться, что маяк восстановился.

Async Terrain Streaming не должен менять формат persistent world.

## 6. Диагностика

Сразу после заметного зависания:

1. нажать `F9`;
2. завершить игру;
3. выполнить:

```powershell
.\EXPORT_TERRAIN_DIAGNOSTICS.ps1
```

Передать полученный ZIP.

## Критерии первой итерации

- CPU generation выполняется в WorkerThreadPool;
- текущая поверхность остаётся активной во время job;
- устаревшая отменённая revision не подключается;
- Godot resources создаются только главным потоком;
- камни commit-ятся не более одного слоя за кадр;
- все стадии имеют timing events;
- нет потери collision после swap;
- маяки и сохранение работают как в v14;
- в логе виден источник оставшихся длинных кадров.

Норматив `50 мс` пока является диагностическим, а не жёсткой гарантией. Один
атомарный вызов `create_trimesh_shape()` или `ArrayMesh` может превысить его. Эта
версия должна точно показать такой случай и подготовить tiled-решение.
