## 3. Расхождения и пробелы (важно для P1+)

1. **4 из 5 A10-адаптеров отсутствуют на диске** (`world_binding_v1.gd`, `matter_resource_mapping_v1.gd`, `world_seam_binding_v1.gd`, `body_construction_binding_v1.gd`). WORLD-COMPAT режим (P11) заблокирован до их появления/реализации. Полигон должен зависеть от их контрактов (frozen invariants выше), а не от копий.
2. **A9 representation-контракты plant-lineage-specific**: вход `plant_multiscale_representation_v1.build(description, tier)` ожидает `description` plant-render формата (`plant_render_description_v1.gd`), а не universal phenotype. Для полигона нужен **reusable adapter** `phenotype_snapshot → render description` (не копия формул). Помечено в строке 10.
3. **Observatory protocol ограничен** тремя сайтами (wet/dry/dark) и фиксированным `treatment(...)`; ExperimentManifest P1 должен расширить входы (custom zones, произвольные founders), не ломая `valid_treatment`-контракт.
4. **Matter catalog обширен, но ecology-side bridge отсутствует** (следствие п.1): explicit-only mapping не с чем вызывать.
5. `ecology_region_*` (P4.1/P4.5) — production-line API с собственными schema `distributed_world_simulator.ecology.*`; polygon должен читать их как trusted contracts, не подменяя ownership-модель.
