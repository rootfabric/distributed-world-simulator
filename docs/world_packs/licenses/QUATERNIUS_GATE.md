# Quaternius license gate

Status: **CLOSED for commits until per-pack verification**

The Quaternius general license was updated on 2026-08-28 to the "QAL" terms,
which forbid redistributing assets as standalone assets. Some older pages
(still) indicate CC0 for individual kits. The conflict is unresolved without
checking a concrete pack/version.

## Rules

1. No Quaternius file may be committed to this repository until the specific
   pack + version + current license text is verified and the verification is
   recorded below with URLs and a download-date checksum.
2. Local evaluation of Quaternius kits is allowed outside git, but the
   evaluation artifacts must never enter `assets/third_party/` without rule 1
   being satisfied.
3. Preferred alternatives remain CC0-first sources: Poly Haven, ambientCG,
   Kenney (see `AGENT_CONTENT_SCOUT.md`).
